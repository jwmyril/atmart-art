# art.atmart.ltd — ATM+ Art

Site autonome de la ligne d'art numérique d'Atmart LLC : galerie, collection,
offres maison / business / institutions, diaspora, fiches d'œuvre, processus de
création, FAQ et conditions de vente. Quatre langues (fr · ht · en · es),
installable comme application (PWA), consultable hors connexion.

- **Adresse canonique** : `https://art.atmart.ltd`
- **URL courte imprimée** : `https://atmart.ltd/o/<slug>` — gravée dans les QR,
  elle ne change jamais ; atmart.ltd la redirige vers la fiche.
- Les anciennes adresses `atmart.ltd/atelier*`, `/oeuvres/*`, `/impact`, `/faq`,
  `/conditions-vente`, `/processus-creation` redirigent ici.

La fabrication est décrite dans `tools/README.md` : les pages et les ressources
sont **générées** depuis `Atmart_website`, jamais éditées à la main ici.
